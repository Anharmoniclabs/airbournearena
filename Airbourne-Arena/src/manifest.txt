# Build order for Airbourne-Arena/index.html.
#
# This file IS the dependency graph. The game is one shared function scope, not
# a set of modules: every part below is concatenated into a single IIFE, so a
# part may use any name declared in a part above it, and — because function
# declarations hoist within their own part — any function declared in a part
# below it, as long as the call happens after load. Only code that RUNS at load
# time is order-sensitive. There is exactly one place in the file that depends
# on this rule; it is commented at src/game/34-hangar-characters.js.
#
# Reorder with care. Add new parts next to the ones they belong with, not at
# the end. Rebuild with: npm run build:game (from source/).
